Keys

space
pause / play (the buttons Pause and Play do each half)
c
chain: red = current spike, coloured = its 41 ms context, blue = predicted spike
n / b
next / back, spike by spike (with the chain: context, prediction, window shift)
d
delay lines from the spikes of the 41 ms window (dashed box) which ends at the predicted spike, to it
s
shade the last 41 ms before the present (always shown with the chain)
k / l
slower / faster
r
reset the view (1000 neurons, 1 s, speed ×1)
f / z
fullscreen / zen mode
? or h
this help

Trackpad and mouse

two-finger scroll
horizontal: move in time (pauses) · vertical: move through the neurons
pinch
zoom the time window (ctrl + wheel)
option + pinch
zoom the neurons around the pointer (alt + wheel); a trackpad pinch has no direction

Touch screen

one finger
drag to move in time and through the neurons
two fingers
spread horizontally = zoom the time window · spread vertically = zoom the neurons
click anywhere to close
