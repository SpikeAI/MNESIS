Keys

space
pause / play: a pause waits for the closest next spike and stops on it (press again to cancel); the buttons Pause and Play do each half
c
chain: the current spike and its 41 ms context window in colour; the next spike is blue
n / b
next / back, spike by spike (with the chain, the context window moves onto the next spike)
d
with the chain, paused: explains one prediction in 3 presses — (1) the next spike and the dashed box of the 41 ms before it, (2) the delays from the spikes of the box to it, (3) the context window moves onto it. While playing: show / hide the delay lines
s
shade the last 41 ms before the present (always shown with the chain)
k / l
slower / faster
r
reset the view (all neurons, the 3 s period, speed ×1) and the colours of the chain
f / z
fullscreen / zen mode
? or h
this help

Trackpad and mouse

two-finger scroll
horizontal: move in time (pauses) · vertical: move through the neurons
pinch
zoom the time window (ctrl + wheel)
option + pinch
zoom the neurons around the pointer (alt + wheel); a trackpad pinch has no direction

Touch screen

one finger
drag to move in time and through the neurons
two fingers
spread horizontally = zoom the time window · spread vertically = zoom the neurons
click anywhere to close
